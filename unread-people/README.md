# 읽지 않은 사람들 — THE UNREAD ARCHIVE

검색형 미스터리 웹게임. React 18 + Vite + TypeScript, 별도 서버/DB 불필요.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 표시되는 주소(기본 http://localhost:5173)를 엽니다.

## Vercel 배포

1. 압축 해제 후 프로젝트 폴더를 GitHub 저장소에 올립니다.
2. Vercel → Add New → Project → 저장소 Import.
3. Framework Preset: **Vite**, Build Command: `npm run build`, Output Directory: `dist`.
4. Deploy를 누릅니다. `vercel.json`이 자동 라우팅을 처리합니다.

## 기능

- 자유 키워드 검색(제목, 본문, 작성자, 댓글, 태그) 및 게시판 탐색
- 모바일 반응형 UI / 읽기 화면 / 댓글 / 비교 문서
- 증거 북마크, 읽음 상태, 진행률, 힌트, 권한 잠금
- 4문항 증거 기반 최종 보고서 / 3가지 엔딩
- localStorage 자동 저장, 설정에서 초기화

## 게임 진행 안내 (스포일러)

1. `종이학`, `03:33`, `댓글`을 조사합니다.
2. `P005`, `P009`를 읽고 **빈방** 게시판에서 접근 요청을 누릅니다.
3. 빈방의 `D013`, `D022` 등 증거를 조사합니다.
4. `M016`(개인 메시지)을 읽고 **복원 기록실**에서 열람 요청을 누릅니다.
5. `D017`, `D021`, `D038`, `D023`, `M024`를 확인합니다.
6. 보고서에 정답 및 적절한 근거를 선택합니다.

현재 시나리오는 **출시 가능한 플레이형 초안**으로, 핵심 미스터리와 3종 엔딩까지 이어집니다. 목표 분량 100개 중 현재 약 40개 문서를 수록했으며 추가 문서는 `src/data.ts`의 `docs` 배열에 같은 형식으로 넣으면 됩니다. 별도 온라인 계정, 서버, 실제 AI 생성 기능은 포함되지 않습니다.

## 편집 위치
- `src/data.ts`: 게시글/댓글/문서/검색어/증거 목록
- `src/main.tsx`: UI 및 조사 엔진, 엔딩 판정
- `src/style.css`: 스타일

## 주의사항

본 작품은 창작된 허구입니다. 게임 안의 사망/의료/통신/행정 자료는 실제 자료가 아닙니다. Google Fonts 연결이 차단된 환경에서는 시스템 기본 글꼴을 사용합니다. 저장 내용은 해당 브라우저/기기에만 보존되며 브라우저 데이터를 지우면 소실됩니다.
